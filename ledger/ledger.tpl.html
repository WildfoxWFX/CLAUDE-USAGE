    Live usage from every PC

    Instead of exporting files, each PC can report by itself: Claude Code sends its usage, as it happens, to a small collector you run (the collector folder in the repository: one click to deploy on Render, or node collector/server.js on any always-on PC). The collector’s setup page writes each PC’s settings for you. Paste the collector’s address and read key here, and this page shows every PC that reports to it, refreshed every minute.

    Add another PC

    Without a collector, a PC can still be added by hand. On each PC (it needs Node.js from nodejs.org), paste this into PowerShell. It writes usage_<PC name>.json in the current folder, with the PC’s name, IP address and system details inside. Then open this page on that PC, choose the file and click Add PC: the form fills itself in from the file. Several PCs? Choose all their files at once: each file names its own PC, so one click adds them all. Files that do not come from this command all go into the one PC named in the form. The file itself is read in your browser and is never uploaded; only the daily totals in it are saved (see below). Only Claude models are kept.

    $n=$env:COMPUTERNAME;$ip=$null;$r=Get-NetRoute -DestinationPrefix 0.0.0.0/0|Sort-Object RouteMetric|Select-Object -First 1;if($r){$ip=(Get-NetIPAddress -AddressFamily IPv4 -InterfaceIndex $r.InterfaceIndex|Select-Object -First 1).IPAddress};if(-not $ip){$ip=(Get-NetIPAddress -AddressFamily IPv4|Where-Object{$_.IPAddress -notmatch '^(127|169\.254)\.'}|Select-Object -First 1).IPAddress};$o=Get-CimInstance Win32_OperatingSystem;$c=Get-CimInstance Win32_Processor|Select-Object -First 1;$s=Get-CimInstance Win32_ComputerSystem;$sys="$($o.Caption.Trim()) | $($c.Name.Trim()), $($s.NumberOfLogicalProcessors) threads | $([int]($s.TotalPhysicalMemory/1GB)) GB RAM";$x=$null;foreach($k in 'npx.cmd','npx.exe','npx'){if(-not $x){$g=Get-Command $k -ErrorAction SilentlyContinue|Select-Object -First 1;if($g){$x=$g.Source}}};if(-not $x){'Node.js was not found. Install the LTS version from https://nodejs.org, then close this window, open a NEW PowerShell window and paste the command again.'}else{'Collecting usage with ccusage. The first run downloads it and can take a minute...';$env:npm_config_update_notifier='false';$u=(& $x -y ccusage@latest daily --breakdown --json) -join "`n";if($u -notmatch '"model(Name)?"\s*:'){if($u -match '\{'){'ccusage ran but found no Claude Code usage for this Windows user (it looks in %USERPROFILE%\.claude, or in CLAUDE_CONFIG_DIR if set). Claude Code used inside WSL or by another Windows user is not seen.'}else{'ccusage did not return any data. Read the message above, then try again.'}}elseif($u -match '(?s)\{.*\}'){$pc=@{name=$n;ip=$ip;system=$sys}|ConvertTo-Json -Compress;$f=Join-Path $PWD "usage_$n.json";try{Set-Content -LiteralPath $f -Value "{`"pc`":$pc,`"usage`":$($Matches[0])}" -Encoding UTF8 -ErrorAction Stop;"Wrote $f"}catch{"Could not save $f : $($_.Exception.Message)"}}else{'ccusage did not return any data. Read the message above, then try again.'}}
    Prefer to type the name, IP and system yourself?

    Run this instead (replace NAME with the PC’s name), choose the file, and fill in the fields below. If Windows PowerShell says running scripts is disabled, type npx.cmd instead of npx.

    npx ccusage@latest daily --breakdown --json > usage_NAME.json

    Adding again with the same name and IP merges into that row. Days and models already on file are replaced by the newer file, so re-adding a fresh export never double counts. System details you type replace the earlier ones; leave the field empty to keep them. To keep two installs on one PC apart, give them different names.
