Set up a PC

Each PC that runs Claude Code sends its usage here by itself, as it happens. Nothing to export or upload afterwards. Set up one PC at a time: type the name of the person who uses it, then run the command on that PC.

Windows: paste into PowerShell on that PC

Any PowerShell window works, no administrator rights needed. It fills member.host with the PC’s own name.

macOS or Linux: paste into Terminal on that PC

Or edit the settings file by hand

Merge this into %USERPROFILE%\.claude\settings.json on Windows or ~/.claude/settings.json on macOS and Linux, keeping whatever else is in the file. It must be this user-level file: Claude Code ignores telemetry settings placed in a project’s .claude/settings.json.

Then

  1. Close Claude Code on that PC and start it again. The settings are read at start.
  2. After its next prompt, the PC appears on the dashboard within about a minute, as “ · PC name”.
  3. Nothing appears? Start Claude Code once as CLAUDE_CODE_OTEL_DIAG_STDERR=1 claude (PowerShell: $env:CLAUDE_CODE_OTEL_DIAG_STDERR=1; claude) and read the exporter errors it prints. A wrong key gives 401; a wrong address gives a connection error.

Each PC gets its own member.id (person@pc-name), so the same person on two PCs shows as two rows. Running the command again on the same PC updates it in place. Only token counts, model names, costs and session ids are sent; prompts and responses are not.
