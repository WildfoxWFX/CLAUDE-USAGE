Set up a PC

Each PC that runs Claude Code reports its usage here by itself. Nothing to export or upload afterwards. Set up one PC at a time: type the name of the person who uses it, then run one command on that PC.

Two ways, pick one per PC. The usage agent is a small MCP server that Claude Code starts with every session: it reads the PC’s own Claude Code logs, so it also sends the history already on the PC, and it gives Claude three tools (usage_summary, usage_status, usage_sync_now) so anyone can ask Claude what the team used. The telemetry way needs no extra program but only counts from the moment it is switched on.

Usage agent, Windows: paste into PowerShell on that PC

Needs Claude Code and Node.js (the LTS from nodejs.org) on the PC; the command says so if Node.js is missing. No administrator rights. It downloads the agent from this server into %USERPROFILE%\.claude-usage and registers it with claude mcp add for every project. Run it again any time to update.

Usage agent, macOS or Linux: paste into Terminal on that PC

Telemetry instead, Windows: paste into PowerShell on that PC

Any PowerShell window works, no administrator rights needed. It fills member.host with the PC’s own name. Do not use both ways on one PC; if you do, the agent’s figures win.

Telemetry, macOS or Linux: paste into Terminal on that PC

Telemetry by hand: edit the settings file

Merge this into %USERPROFILE%\.claude\settings.json on Windows or ~/.claude/settings.json on macOS and Linux, keeping whatever else is in the file. It must be this user-level file: Claude Code ignores telemetry settings placed in a project’s .claude/settings.json.

Then

  1. Close Claude Code on that PC and start it again. Both ways are read at start.
  2. With the agent, the PC and its history appear on the dashboard within a minute of the next session starting, as “ · PC name”. With telemetry, it appears after the next prompt.
  3. Agent not showing? In Claude Code type /mcp to see whether claude-usage connected, or ask Claude to run usage_status. Telemetry not showing? Start Claude Code once as CLAUDE_CODE_OTEL_DIAG_STDERR=1 claude (PowerShell: $env:CLAUDE_CODE_OTEL_DIAG_STDERR=1; claude) and read the exporter errors. A wrong key gives 401; a wrong address gives a connection error.

Each PC gets its own id (person@pc-name), so the same person on two PCs shows as two rows. Running a command again on the same PC updates it in place. Only token counts, model names, costs and session ids leave the PC; prompts and responses do not.
